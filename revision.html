NAND and NOR are universal: each can build every other gate. A NAND with its inputs tied is a NOT; NAND–NAND realises any SOP, NOR–NOR any POS.

Numbers and codes

  • n-bit unsigned: 0 to 2ⁿ − 1. Two's complement: −2ⁿ⁻¹ to 2ⁿ⁻¹ − 1.
  • Two's complement = invert every bit, then add 1. Overflow happens when two numbers of the same sign give a result of the other sign.
  • BCD stores each decimal digit in 4 bits; 1010–1111 are invalid. BCD addition: if a digit sum exceeds 9 or carries, add 0110.
  • Gray code changes one bit per step: G = B ⊕ (B ≫ 1). That is why K-map rows and columns go 00, 01, 11, 10.
  • Excess-3 = BCD + 0011. It is self-complementing.

K-maps in brief

  • Group 1s for SOP, 0s for POS. Groups are rectangles of 1, 2, 4, 8… cells and may wrap round the edges and corners.
  • Make every group as big as possible, use as few groups as possible, and use don't cares (X) only when they help.
  • A prime implicant cannot grow any bigger. An essential one covers a 1 that no other prime implicant covers.
  • Each group of 2ᵏ cells removes k variables from the term.

  • A 2ⁿ:1 MUX needs n select lines and can implement any n-variable function (or n+1 variables with an inverter).
  • A decoder turns n inputs into 2ⁿ outputs, one per minterm. OR the right outputs together to make any function.
  • A priority encoder outputs the index of the highest active input.

Flip-flops

Characteristic equations

  • SR: Q⁺ = S + R′Q (SR = 1 forbidden)
  • JK: Q⁺ = JQ′ + K′Q
  • D: Q⁺ = D
  • T: Q⁺ = T ⊕ Q

Excitation table

Q → Q⁺S RJ KDT
0 → 00 X0 X00
0 → 11 01 X11
1 → 00 1X 101
1 → 1X 0X 010

A latch is level-sensitive; a flip-flop acts on a clock edge. Preset and clear are asynchronous and override the clock. JK with J = K = 1 toggles; if it toggles more than once while the clock is high, that is the race-around problem, which edge triggering and master–slave designs avoid.

Counters and registers

  • A mod-N counter needs ⌈log₂ N⌉ flip-flops.
  • Ripple (asynchronous): each flip-flop clocks the next. Simple but delays add up, so outputs glitch briefly.
  • Synchronous: one clock to all flip-flops; faster, no ripple glitches.
  • Mod-N by reset: decode state N and drive the asynchronous clear (for example a 74161 cleared by NAND(QD, QB) gives mod-10).
  • 7490 in BCD mode: QA to CKB, clock into CKA. 7493 as mod-16: same QA to CKB link.
  • Ring counter: N flip-flops, N states. Johnson (twisted ring): N flip-flops, 2N states.
  • Shift registers: SISO, SIPO (74164), PISO, PIPO; the 74194 does all four plus left/right shifting.

Circuit laws

  • Ohm: V = IR. Power: P = VI = I²R = V²/R.
  • KCL: currents into a node sum to zero. KVL: voltages round a loop sum to zero.
  • Series: R = R₁ + R₂. Parallel: R = R₁R₂ / (R₁ + R₂). Capacitors combine the other way round.
  • Divider: Vout = Vin R₂ / (R₁ + R₂).
  • Thevenin: Vth is the open-circuit voltage; Rth is seen with sources zeroed (V shorted, I opened). Norton: IN = Vth / Rth.
  • Maximum power transfer when RL = Rth.

RC, RL, RLC

  • τ = RC or L/R. After 1τ a charging capacitor reaches 63 %; after 5τ it is considered done.
  • vC(t) = V(1 − e−t/τ) charging, V e−t/τ discharging.
  • XC = 1 / (2πfC), XL = 2πfL.
  • First-order cut-off: fc = 1 / (2πRC). At fc the output is −3 dB (0.707×) with a 45° phase shift.
  • Resonance: f₀ = 1 / (2π√(LC)). Series Q = (1/R)√(L/C). Critical damping at R = 2√(L/C).

Op-amps

Ideal: infinite gain and input impedance, zero output impedance. With negative feedback, the two inputs sit at the same voltage (virtual short) and draw no current.

InvertingVo = −(Rf/Rin)Vin
Non-invertingVo = (1 + Rf/Rg)Vin
FollowerVo = Vin
SummingVo = −Rf(V₁/R₁ + V₂/R₂ + …)
DifferenceVo = (Rf/R₁)(V₂ − V₁), matched resistors
IntegratorVo = −(1/RC)∫Vin dt
DifferentiatorVo = −RC dVin/dt

No feedback means a comparator: the output swings to whichever rail the input difference points to.

Quick viva answers

  • Why are NAND and NOR called universal? Either one alone can build AND, OR and NOT, so any circuit at all.
  • Why does a K-map use Gray order? So neighbouring cells differ in one variable, which is what lets a group drop it.
  • Latch or flip-flop? A latch follows its input while enabled; a flip-flop samples only at the clock edge.
  • Why is a ripple counter slow? Each stage waits for the previous one, so delays add up along the chain.
  • What does an unused TTL input do? It floats HIGH but is noisy, so tie it to VCC (via a resistor) or to GND, depending on the gate.
  • Why a bleeder or load resistor on a filter capacitor? It discharges the capacitor once the supply is off.
